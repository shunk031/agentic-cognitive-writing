---
name: reviewing
description: Checks .writing/draft.md against the task and goals, revises it within the requested scope, and reports what is needed next. Use only when the Monitor delegates the reviewing role.
---

Work in `.writing/` under the current working directory.

1. Read `task.md`, `goals.md`, and `draft.md`.
2. Check the draft against the task and the goals, and revise `draft.md` only within the scope the request names.
3. Edit `draft.md` with the file-editing tool, never through the shell.
4. Write draft text in the output language the task specifies, or in the language of the task's instructions if it specifies none.
5. Write no file other than `draft.md`.
6. Reply whether planning, drafting, or another review is needed next, and name any goal you recommend replacing, with the reason.
