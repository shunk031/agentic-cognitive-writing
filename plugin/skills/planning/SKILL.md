---
name: planning
description: Creates or develops the writing goals in .writing/goals.md.
---

Work in `.writing/` under the current working directory.

1. Read `task.md`, and `draft.md` and `goals.md` if they exist.
2. Create or develop goals in `goals.md` for the task's audience and purpose: a nested list, one goal per line, each with an ID such as `G1` or `G1.1`.
3. Replace a goal only when the request says the `Monitor` accepted that replacement.
4. Write `goals.md` with the file-editing tool, never through the shell.
5. Write in the output language the task specifies, or in the language of the task's instructions if it specifies none.
6. Write no file other than `goals.md`.
