name: translating
description: Writes the requested scope of .writing/draft.md toward the goals in .writing/goals.md.
---

Work in `.writing/` under the current working directory.

1. Read `task.md`, `goals.md`, and `draft.md` if it exists.
2. Write only the scope of `draft.md` that the request names.
3. Edit `draft.md` with the file-editing tool, never through the shell.
4. Write in the output language the task specifies, or in the language of the task's instructions if it specifies none.
5. Write no file other than `draft.md`.
6. Reply with any structural problem you found while drafting.
