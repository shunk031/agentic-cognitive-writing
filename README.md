This repository contains the `agentic-cognitive-writing` plugin for Claude Code and OpenAI Codex, which operationalizes ["A Cognitive Process Theory of Writing"](https://www.jstor.org/stable/356600) by Flower and Hayes (1981)[^1]; see [plugin/README.md](plugin/README.md) for installation, architecture, state files, and trace format, while the repository also hosts research and experiments.

[^1]: Linda Flower and John R. Hayes. "A Cognitive Process Theory of Writing." College Composition and Communication 32(4), 1981, pp. 365-387. Canonical DOI: [10.58680/ccc198115885](https://doi.org/10.58680/ccc198115885). The DOI endpoint returned HTTP 403 in this environment, so the title above links to the resolvable [JSTOR record](https://www.jstor.org/stable/356600).
