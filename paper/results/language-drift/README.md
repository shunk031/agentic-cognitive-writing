# Output-language drift

[`language-drift.json`](language-drift.json) is the output of [`language_drift.py`](../../../experiments/src/agentic_cogwriter/analysis/language_drift.py) over generation run 1, with the A8 and A9 run roots added so that every run-1 condition is covered. A text counts as mainly Chinese when its Chinese characters outnumber its Latin letters, the rule `scripts/make_numbers.py` uses for prompt language. For each benchmark the file gives, per condition, the completed outputs of English prompts and how many of them are mainly Chinese, plus the prompts that are mainly Chinese in every condition and which of those prompts contain Chinese text. Regenerate its macros with `python3 scripts/make_numbers.py --language-drift results/language-drift/language-drift.json` from `paper/`.
