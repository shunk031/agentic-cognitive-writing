# Cross-family pairwise judge

[`cross-family-summary.json`](cross-family-summary.json) holds the cross-family robustness check on generation run 1. A second judge from another model family, `claude-sonnet-5`, re-judges the pairwise contrasts of Agentic CogWriter (A4) against Single-pass (A1), Staged (A2), Task-planning (A3), No-goals (A5), and Fixed-order (A6). The file reports wins, losses, ties, commit rate, win rate with a Wilson interval, an exact sign test, and agreement with the primary judge `gpt-5.6-sol`, for each contrast and benchmark and pooled over all five contrasts. No multiplicity correction is applied.

The file is produced by [`cross_family.py`](../../../experiments/src/agentic_cogwriter/analysis/cross_family.py). Pairs are scored with [`score_pairwise_batch.py`](../../scripts/score_pairwise_batch.py), and a pair counts only when both judges completed both presentation orders for the same canonical runs.

**Judge settings.** Every contrast uses the same settings: model `us.anthropic.claude-sonnet-5` over the Bedrock Converse API, medium effort, 8192 maximum output tokens, seed and presentation seed 20260908, two retries, and the [`pairwise-v1`](../../../experiments/prompts/judges/pairwise-v1.md) prompt. Each contrast's `judge_routes` field records how requests reached Bedrock. A4:A1, A4:A3, and A4:A5 went through a gateway, and A4:A2 and A4:A6 went directly to Bedrock.
