We study long-form writing as an architecture problem for AI agents. \condAgenticCogWriter\ uses a coding-agent-style harness in which a host agent repeatedly inspects persistent writing state and delegates planning, drafting, or reviewing to specialized agents. Across three long-form benchmarks, the system is competitive on pointwise and benchmark-native quality measures and is preferred in matched-output comparisons to one-shot generation, a fixed staged workflow, and adaptive task planning under our primary evaluation.

The component results are equally important. Removing the explicit goal network or fixing the process order does not significantly worsen pairwise preference, and the unrestricted host agent usually follows the same planning--drafting--reviewing cycle on its own. We therefore view the contribution less as evidence for any single cognitive mechanism than as evidence that process-organized, stateful execution is a promising abstraction for writing agents. As general-purpose agents take on workflows that end in reports, documentation, and scientific papers, understanding how to organize the writing loop itself becomes an increasingly important systems question.
