We design the experiments around three questions: (1) does process-level organization improve document quality relative to alternative writing architectures, (2) which components of \condAgenticCogWriter\ are necessary for any observed advantage, and (3) how does the resulting writing loop behave in practice? The study contains seven pre-specified systems plus one post-hoc execution check, all compared on the same task inputs and under a common generation contract.

\subsection{Systems Compared}
\label{sec:baselines}

\paragraph{Alternative writing architectures.}
We compare \condAgenticCogWriter\ with three ways of organizing long-form generation. The one-shot baseline (\condSinglePass) asks the model to produce the complete document in one call. The fixed-stage baseline (\condStaged) executes \texttt{Pre-Write}$\rightarrow$\texttt{Write}$\rightarrow$\texttt{Re-Write}, following the common pattern of separating planning, drafting, and revision into a prescribed workflow~\citep{yang2022re3,wan2025cognitive}. The adaptive task-planning baseline (\condTaskPlanning) follows a WriteHERE-style task graph~\citep{xiong2025beyond}: it recursively decomposes the assignment and selects among dependency-satisfied task nodes. Thus, the three alternatives respectively advance the whole document, a fixed writing stage, or an adaptive task node, whereas \condAgenticCogWriter\ advances a writing process.

\paragraph{Ablations of \condAgenticCogWriter.}
We next modify one architectural choice at a time while leaving the rest of the process loop intact. \condNoGoals\ removes the explicit goal network but retains adaptive process selection and the specialized agents. \condFixedOrder\ keeps the shared draft, goal network, process history, and specialists but replaces the \texttt{Monitor}'s adaptive decision with the repeated \texttt{Planning}$\rightarrow$\texttt{Translating}$\rightarrow$\texttt{Reviewing} cycle. These ablations test how much explicit goal bookkeeping and adaptive process order contribute to the full system's performance.

\paragraph{Execution variants.}
We also probe whether the way writing processes are executed can explain the result. \condSingleWriter\ retains the goal network and process-level loop but performs planning, drafting, and reviewing in one writer context without role-agent delegation; it also limits each \texttt{Translating} step to one paragraph before the next process decision. Because those changes are bundled, this condition is diagnostic rather than a clean ablation. After observing the main results, we added \condSingleContext\ as a narrower exploratory check: it preserves the full process loop and shared state but executes each selected process in the \texttt{Monitor}'s context rather than in a separate role-agent context. The run also differs in gateway entry point and transport, so we use it only to constrain, rather than establish, a role-context explanation.
