Long-form writing requires decisions about both \emph{what} to write and \emph{how} to proceed. Language-model writing systems externalize many of these decisions through plans, outlines, task decomposition, feedback, and revision~\cite{yang2022re3,madaan2023self,shao2024assisting,bai2025longwriter,xiong2025beyond}. We use \emph{controller} to refer to the part of a writing agent that determines what operation happens next. Existing controllers differ substantially in implementation, but they commonly advance a plan element, passage, section, or task node, or execute a prescribed sequence of operations. In other words, the controller usually selects a content item or task rather than the writing process itself. This leaves a basic design question open: \emph{what should a writing agent be able to choose next?}

The cognitive process theory of writing~\cite{flower1981cognitive} suggests one concrete answer. Flower and Hayes describe \texttt{Planning}, \texttt{Translating}, and \texttt{Reviewing} as recurrent processes coordinated by a \texttt{Monitor}, and propose that writer-generated goals can change as composition proceeds. Later accounts revise and extend this model~\cite{hayes1996new,hayes2012modeling}, but the 1981 formulation is especially useful for agent design because it makes several control commitments explicit: the writing processes form the available operations, their order can adapt during composition, and writing is guided by an evolving goal structure. We treat these commitments as experimentally separable hypotheses about agent control, not as a blueprint that should be copied wholesale or as a claim that a language agent reproduces human cognition. The resulting question is therefore not whether cognitive writing theory can be implemented in an agent, but which of its control commitments matter once made executable.

From this perspective, we formulate \emph{process-level control}: the controller chooses which writing process to execute next. We instantiate this formulation as Agentic CogWriter, a writing agent built on a coding-agent harness. Agentic CogWriter maintains three external records while writing: the current draft, an explicit hierarchical representation of current writing goals, and a history of previous process choices and goal changes. We call the goal representation the \emph{goal network}. The host agent implements the \texttt{Monitor}, which reads these records and chooses \texttt{Planning}, \texttt{Translating}, or \texttt{Reviewing}; the corresponding \texttt{Planner}, \texttt{Translator}, or \texttt{Reviewer} role agent then executes that process before control returns to the \texttt{Monitor}. This operationalization makes two theory-derived commitments directly testable: explicit goal representation and adaptive process ordering. It also exposes separated role contexts as an implementation choice that can be probed experimentally. The first two admit confirmatory single-factor interventions; role-context separation is examined with diagnostic and post-hoc exploratory comparisons.

We ask three research questions. \textbf{RQ1} asks whether organizing generation around writing processes improves long-form writing relative to generation with no intermediate choice, a fixed stage sequence, and adaptive choice over task nodes. \textbf{RQ2} asks what interventions reveal about the explicit goal representation, adaptive process ordering, and separated role contexts. \textbf{RQ3} asks what observable process traces reveal about how the \texttt{Monitor} actually uses process-selection flexibility and goal changes during writing.

We evaluate Agentic CogWriter on long-form writing tasks from three complementary benchmarks: WritingBench~\cite{wu2026writingbench}, HelloBench~\cite{que2024hellobench}, and DoLoMiTes~\cite{malaviya2025dolomites}. Within each benchmark, a pre-specified rule selects the longest-output slice, where control choices have more opportunity to affect composition. Using the same generator and coding-agent harness, we compare Agentic CogWriter with single-call generation, a fixed three-stage workflow, and adaptive task planning across three independent replications. Agentic CogWriter is preferred to all three baselines. The mechanism results are more selective: removing the explicit goal representation or replacing adaptive process choice with a fixed \texttt{Planning}$\rightarrow$\texttt{Translating}$\rightarrow$\texttt{Reviewing} cycle produces no detectable loss. The process traces further show that the unrestricted \texttt{Monitor} usually follows that cycle, while accepted goal regeneration is rare and the explicit goal network is generally stable during a run. The diagnostic \condSingleWriter\ condition performs substantially worse, but it changes several execution factors together. In a post-hoc exploratory check that retains the process loop while collapsing execution into one agent context, there is likewise no detectable pooled loss against Agentic CogWriter. Thus, the experiments support process-organized generation relative to the tested baselines, while neither the confirmatory interventions nor the exploratory role-context check identifies a single mechanism that explains the observed advantage.

Our contributions are threefold. First, we frame long-form writing-agent design around what the controller chooses next, distinguishing content or task selection from process-level control. Second, we turn two commitments from cognitive writing theory into executable hypotheses whose goal representation and process ordering can be intervened on directly, and separately probe role-context separation as an implementation choice with lower-tier diagnostic evidence. Third, across three benchmarks and replications, Agentic CogWriter's process-organized design is preferred to the tested baseline organizations, while the confirmatory interventions do not identify explicit goal bookkeeping or adaptive process ordering as sources of that advantage, and the exploratory \condSingleContext\ check does not support separated role contexts as its explanation. Together, these results show how cognitive theory can serve not only as architectural inspiration, but as a source of falsifiable design hypotheses for language agents.
