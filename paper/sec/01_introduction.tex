Long-form writing requires decisions about both \emph{what} to write and \emph{how} to proceed. Language-model writing systems externalize many of these decisions through plans, outlines, task decomposition, feedback, and revision~\cite{yang2022re3,madaan2023self,shao2024assisting,bai2025longwriter,xiong2025beyond}. We use \emph{controller} to refer to the part of a writing agent that determines what operation happens next. Existing controllers differ substantially in implementation: some advance a plan element, passage, section, or task node, while others execute a prescribed sequence of operations. In both cases, the set of writing processes is not itself the action space from which the controller repeatedly chooses. This leaves a basic design question open: \emph{what should a writing agent be able to choose next?}

The cognitive process theory of writing~\cite{flower1981cognitive} suggests one concrete answer. Flower and Hayes describe \texttt{Planning}, \texttt{Translating}, and \texttt{Reviewing} as recurrent processes coordinated by a \texttt{Monitor}, and propose that writer-generated goals can change as composition proceeds. Later accounts revise and extend this model~\cite{hayes1996new,hayes2012modeling}, but the 1981 formulation is especially useful for agent design because it makes three aspects of control explicit: writing processes form the available operations, their order can adapt during composition, and writing is guided by an evolving goal structure. We treat these as design hypotheses about agent control, not as a blueprint to copy wholesale or as a claim that a language agent reproduces human cognition. The resulting question is not whether cognitive writing theory can be implemented literally, but what happens when its control commitments are made executable and tested separately.

We therefore formulate \emph{process-level control}: the controller chooses which writing process to execute next. We instantiate this formulation as \condAgenticCogWriter, a writing agent built on a coding-agent harness. It maintains three external records while writing: the current draft, an explicit hierarchical representation of current writing goals, and a history of previous process choices and goal changes. We call the goal representation the \emph{goal network}. The host agent implements the \texttt{Monitor}, which reads these records and chooses \texttt{Planning}, \texttt{Translating}, or \texttt{Reviewing}; the corresponding \texttt{Planner}, \texttt{Translator}, or \texttt{Reviewer} role agent then executes that process before control returns to the \texttt{Monitor}. This architecture lets us compare the process-organized system with alternative control organizations, and then intervene on two theory-derived commitments within it: explicit goal representation and adaptive process ordering. Separated role contexts are an additional implementation choice that we probe with lower-tier diagnostic and exploratory evidence.

We ask three research questions. \textbf{RQ1} asks whether a process-organized writing agent is preferred to generation with no intermediate choice, a fixed stage sequence, and adaptive choice over task nodes. \textbf{RQ2} asks what single-factor interventions on explicit goal representation and adaptive process ordering, together with diagnostic checks on role-context separation, reveal about the observed difference. \textbf{RQ3} asks how the \texttt{Monitor} actually uses process-selection flexibility and goal regeneration, and whether variation in its realized process sequences tracks preference outcomes.

We evaluate \condAgenticCogWriter\ on long-form writing tasks from WritingBench~\cite{wu2026writingbench}, HelloBench~\cite{que2024hellobench}, and DoLoMiTes~\cite{malaviya2025dolomites}, using a pre-specified longest-output slice from each benchmark. On benchmark-native scores and a standardized pointwise composite, \condAgenticCogWriter\ is competitive but not uniformly best across all benchmarks. In the primary matched-prompt pairwise evaluation, however, it is preferred to single-call generation, a staged \texttt{Pre-Write}$\rightarrow$\texttt{Write}$\rightarrow$\texttt{Re-Write} workflow, and adaptive task planning across independent replications. The mechanism results are more selective: removing the explicit goal representation or replacing adaptive process choice with a fixed \texttt{Planning}$\rightarrow$\texttt{Translating}$\rightarrow$\texttt{Reviewing} cycle produces no detectable loss. The process traces show that the unrestricted \texttt{Monitor} usually follows that cycle and that accepted goal replacement through regeneration is rare. A bundled single-writer intervention performs substantially worse, while a narrower post-hoc same-context check that retains the process loop shows no detectable difference after pooling benchmark outcomes within its exploratory replication. The tested interventions therefore do not identify a single mechanism that explains the pairwise advantage.

Our contributions are threefold. First, we frame long-form writing-agent design around what the controller chooses next, distinguishing content/task control and prescribed stage sequences from process-level control. Second, we use cognitive writing theory to derive an executable process-level organization and two commitments that can be intervened on directly, while separately probing role-context separation as an implementation choice. Third, the experiments reveal a selective pattern: process-organized generation is preferred to the tested baseline organizations, but the confirmatory interventions do not identify explicit goal bookkeeping or adaptive process ordering as sources of that advantage, and exploratory evidence does not support a simple role-context explanation. Together, these results show how cognitive theory can serve as a source of falsifiable design hypotheses for language agents.
