# Result macro schema

Compute-stratified macros use the recorded JSON from [PR 78](https://github.com/shunk031/agentic-cognitive-writing/pull/78) at head `2ca47c4`.

`numbers.tex` is generated by `paper/scripts/make_numbers.py`. The generator
keeps macro names stable while replacing values from the first aggregation
file. Replicate summaries are emitted only when two or more aggregation files
are supplied. Benchmark keys are `DoLoMiTes`, `HelloBench`, and
`WritingBench`; condition ranges below use A1 through A7. Process-trace
macros are emitted from the supplied process-summary JSON files, with the
first source providing run 1 and later sources providing the replicates.

The A8 single-context macros use the copied production analysis packet in
`scratch/a8-stage1/`. The packet records the post-hoc exploratory run label
`a8-stage1-rep1`, the generator `gpt-5.6-luna`, the A8 reachable provider
entry point with plain HTTP Responses, and the baseline's original provider
entry point and default transport. Structural-audit counts are recorded in
the companion JSON with its source note.

The first column uses brace patterns. A comma-separated brace list expands to
one alternative for each item. The coverage test expands these patterns and
checks every `\newcommand` in `numbers.tex`.
